# 50-content-engine — Knowledge Into Content

Every evergreen concept becomes eleven assets, all derived from the same source note so the message never contradicts itself:

1. Long-form YouTube script · 2. Short YouTube script · 3. Reel series · 4. Carousel · 5. LinkedIn post · 6. Blog article · 7. Newsletter · 8. Course notes · 9. Teaching notes · 10. Voice-over script · 11. Product-ready documentation

One folder per concept, tracked with [00-meta/templates/content-asset-set.md](../00-meta/templates/content-asset-set.md). When the source concept changes materially, its assets are flagged stale and reviewed.

# 20-operations — How Work Gets Done

The difference between knowing SEO and shipping it repeatably.

Planned structure:
- `sops/` — one file per repeatable process
- `checklists/` — pure binary verification, paired with SOPs
- `client-deliverables/` — a reusable template for **every** document a client ever receives: proposal, discovery questionnaire, audit report, keyword research, technical audit, content strategy, monthly report, client presentation, email templates, meeting notes. Nothing is ever built from scratch again
- `agency-simulator/` — practice projects that produce real deliverables: mock job postings, onboarding simulations, discovery calls, practice websites, audits, reports, client objections, reporting exercises, review checklists
- `internal-ops/` — pricing, scoping, time tracking, QA

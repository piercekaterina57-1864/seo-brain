# SEO Brain

The permanent knowledge base and operating system for my SEO career.

Everything I learn, build, discover, practice and deliver lives here. Nothing important stays inside a chat window, a Google Doc, or my head. If it is reusable, it belongs in this repository.

This repo is plain Markdown and plain folders. No proprietary formats, no database, no account required. It renders on GitHub, opens in Obsidian or VS Code, and will still work in ten years.

## The three rules

1. **One canonical location per asset.** A checklist exists once. Everything else links to it.
2. **Every file follows the documentation standard.** See [00-meta/DOCUMENTATION-STANDARD.md](./00-meta/DOCUMENTATION-STANDARD.md).
3. **Every note declares its connections.** `prerequisites` (up), `related` (sideways), `next` (forward). This is what makes the knowledge map navigable.

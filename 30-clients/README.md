# 30-clients — Client Workspaces

One folder per client, instantiated from [00-meta/templates/client-workspace-readme.md](../00-meta/templates/client-workspace-readme.md).

Standard sub-structure: `01-proposal/` · `02-discovery/` · `03-audits/` · `04-strategy/` · `05-deliverables/` · `06-reporting/` · `07-meetings/` · `08-work-log/` · `assets/`

**Rules:** client work instantiates templates from `20-operations/client-deliverables/` and records the template version used. Credentials are never stored here — only a note of where access lives. Nothing leaves this folder for the portfolio without passing the redaction rules.

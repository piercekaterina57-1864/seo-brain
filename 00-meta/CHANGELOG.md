## 2026-07-25 — v0.2 — `00-meta/` system built

Documentation standard v1.0, naming conventions v1.0, taxonomy v1.0, workflows v1.0, master knowledge map v1.0, agent briefing v1.0, and the full template set v1.0. Root README and folder skeleton created.

## 2026-07-25 — v0.1 — Architecture established

Ten-folder numbered structure agreed. Decisions recorded: numbered top-level folders with gaps for insertion; `README.md` as the hub file in every folder; one canonical location per asset with links instead of duplication; three-direction link model (`prerequisites` / `related` / `next`).

Additions to the original design, approved at Step 1: `15-business-playbooks/` as a top-level sibling of `10-knowledge/`; a client deliverables library and an agency simulator under `20-operations/`; `50-content-engine/` expanded to an 11-format asset set.
